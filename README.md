# Homebrew Tap for Rightform

Install [Rightform](https://github.com/prisonmike420/rightform), a native macOS
utility that prepares image files locally.

```zsh
brew install prisonmike420/rightform/rightform
rightform
```

The formula downloads the immutable `v0.16.0` source archive, verifies its
SHA-256, installs the required image engines, then builds and opens
`Rightform.app` locally. It requires macOS 13 or later plus Apple Command Line
Tools or Xcode.
